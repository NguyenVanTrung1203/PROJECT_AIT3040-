## Confirmed vs projected

Confirmed: T04 mock routes are absent from common OpenAPI; feature/rule adapters and model/risk runtime are not implemented; the offline EncounterDataset omits SOG/COG; schema status and integration prose are pending review; mock fixture files exist and are labelled mock.

Projected risks (not observed production failures): pair flip, timestamp leakage, invalid coordinate origin, races in alert state, and invalid status handling. These need runtime tests when the responsible modules exist; the audit does not claim they have occurred.
