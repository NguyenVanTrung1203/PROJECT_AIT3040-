## Repository evidence and reusable components

- `src/data/dataset_loader.py` checks lock/version, declared split shapes, tensor dtypes, parquet/index counts, encounter index, labels, vessel `X_row`, and official A/B mapping.
- `src/data/vessel_dataset.py` returns offline X/Y and vessel mapping. `src/data/encounter_dataset.py` returns X and anchors under `model_input`, and target/label under `ground_truth`; it does not return SOG/COG history.
- `scripts/verify_feature_contract.py` contains offline EN/velocity/as-of/pair-ID reference helpers, but its pair ID helper is a proposal, not the T08 runtime adapter.
- `backend/app/mock_tracks.py` implements only four deterministic `SYNTHETIC_AIS` examples; `backend/app/main.py` exposes read-only health/list/detail mock routes.
- Tests present: `tests/unit/test_api_contract.py`, `tests/unit/test_feature_contract.py`, `tests/unit/test_dataset_loader.py`, `tests/unit/test_tensor_contract.py`, `tests/unit/test_cpa_contract.py`, `tests/unit/test_model_config.py`, `tests/integration/test_mock_contracts.py`, `backend/tests/test_mock_api.py`, and `frontend/src/App.test.jsx`.
